# Gopher artwork

- `gopher.png`: transparent monochrome mascot used as the menu bar template image.
- `gopher-app.png`: application artwork. `scripts/bundle.sh` creates the standard and Retina icon sizes and packages them as `Gopher.icns`.

The application artwork was generated with the built-in image-generation tool, using `gopher.png` as the reference and this prompt:

> Use case: logo-brand. Asset type: macOS application icon, square 1024x1024 PNG. Input image is the existing Gopher mascot reference: a black monochrome cartoon gopher on transparent background, with its silhouette defined by the alpha channel. Create a polished application-icon version of this same mascot, preserving its recognizable rounded gopher head, ears, eyes, nose and buck teeth. Keep the mascot monochrome black with white facial cutouts, crisp clean simple shapes. Place it large and centered on an off-white rounded-square macOS icon tile with a very subtle edge/shadow and transparent pixels outside the tile. Tile occupies about 88% of canvas width with symmetrical margins; mascot occupies about 68% of canvas. Straight-on flat icon, no perspective, no text, no additional objects, no badge. This is the final usable icon asset, not an icon displayed in a mockup or screenshot.
